# BRAF G469A

This is another constitutive dimer. In this directory, I have the BRAF exons 11 - 18 with this mutation as well as the loss of function mutation (R509H).

## G469A

This is a SNP within the protein kinase domain of BRAF, causing increased BRAF kinase activity and thus increases activation of ERK leading to oncogenesis. This mutation takes takes place at position 1406 (G > C) accoding to cDNA

https://ckb.genomenon.com/geneVariant/show?geneVariantId=452

## R509H

This mutant is at position 1526 (G > A) in the nucleotide sequence on exon 13

WT: CGA (Arginine)
Mutant: CAA (Histidine)

www-ncbi-nlm-nih-gov.exaccess.libraries.psu.edu/clinvar/RCV000427215/

# Obtain files

## Generate Makefile

```bash
touch Makefile
```

Run

```bash
make
```

## Generate BAM files

The default `make` target generates the FASTA files and both indexed BAM alignments. To generate only the BAM files, run:

```bash
make bam
```

The BAMs align each mutant FASTA against the wild-type exons 11–18 reference and are written to `bam/`.
