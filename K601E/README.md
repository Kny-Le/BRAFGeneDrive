# BRAF K601E

This is a consitutive dimer, so this could be a good candidate for an inducible dimerization domain. Here, I provide the sequences for both the BRAF K601E and BRAF K601E/R509H double mutant.

## K601E

The BRAF K601E mutation is a class II BRAF mutation and is known to be oncogenic. This mutant arises through an SNP at 1801 (A>G)

https://civicdb.org/variants/584/summary

## R509H

This mutant is at position 1526 (G > A) in the nucleotide sequence on exon 13

WT: CGA (Arginine)
Mutant: CAA (Histidine)

www-ncbi-nlm-nih-gov.exaccess.libraries.psu.edu/clinvar/RCV000427215/

# Making files

Make the makefile

```bash
touch Makefile
```

run:

```bash
make
```

The FASTAs are built from the BRAF mRNA record [NM_004333.6](https://www.ncbi.nlm.nih.gov/nuccore/NM_004333.6/) (RefSeq, MANE Select), using only the coding bases of exons 11–18.

To make BAM files, paste this into your terminal

```bash
cd /Users/kenny/Projects/BRAFGeneDrive/K601E || exit 1
set -euo pipefail

command -v minimap2 >/dev/null || { echo "minimap2 is required"; exit 1; }
command -v samtools >/dev/null || { echo "samtools is required"; exit 1; }

mkdir -p bam
samtools faidx fasta/BRAF_exons11-18.fasta

minimap2 -ax asm5 fasta/BRAF_exons11-18.fasta fasta/BRAF_exons11-18_1526GtoA_1801AtoG.fasta \
  | samtools sort -o bam/BRAF_1526GtoA_1801AtoG_vs_wt.bam -
samtools index bam/BRAF_1526GtoA_1801AtoG_vs_wt.bam

minimap2 -ax asm5 fasta/BRAF_exons11-18.fasta fasta/BRAF_exons11-18_1801AtoG.fasta \
  | samtools sort -o bam/BRAF_1801AtoG_vs_wt.bam -
samtools index bam/BRAF_1801AtoG_vs_wt.bam
```
